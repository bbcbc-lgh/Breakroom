# 赛博小镇产品与体验简报

状态：Approved v1.0，已于 2026-08-02 确认

需求基线：[REQUIRE.md](./REQUIRE.md)

## 1. 一句话定义

赛博小镇是一款 Windows 端俯视角像素互动原型：玩家走进一间正在运转的创意办公室，与三名具有独立人格、关系和持续记忆的 AI NPC 建立联系。

它首先要像一个完整的小型游戏，其次才是 AI 技术演示。玩家应先感受到空间、角色和关系，再意识到背后存在模型、记忆和后端服务。

## 2. 首版玩家承诺

- 一分钟内进入场景并理解如何靠近角色互动。
- 三名 NPC 从外观、工作区域、表达方式和关注话题上均可区分。
- NPC 会记住玩家明确说过的重要事实，而不是只复述最近一句话。
- 关系变化能够被感知、解释和恢复，不是不可控的随机数字。
- AI 或网络失败时，游戏仍是可操作的，不会冻结或崩溃。
- 修改配置并重启后，可以更换 NPC 姓名、性格、职业和其他角色内容。

## 3. 体验支柱

### 3.1 空间先于菜单

第一屏直接进入可玩的办公室，不增加营销页或功能说明页。玩家通过移动、靠近提示和角色反馈理解玩法。

### 3.2 人格来自一致性

人格不是一段长提示词，而是身份、语言习惯、话题偏好、关系阶段、可回忆事实和场景行为共同形成的稳定表现。

### 3.3 AI 不掌管规则

模型负责理解和表达；移动、碰撞、关系计分、数据写入、冷却和错误降级由确定性代码负责。

### 3.4 等待也属于体验

模型响应期间，玩家能看到明确的等待反馈，仍可关闭对话。超时后出现符合角色的简短降级回复，而不是技术错误。

### 3.5 内容可编辑

三名首发 NPC 是默认内容而非代码边界。稳定 `npc_id` 与显示姓名分离，修改角色内容不会破坏历史关系和记忆。

## 4. 核心玩法闭环

1. 玩家在办公室中探索三个具有不同视觉主题的工作区域。
2. 玩家靠近一名 NPC，看到单一、明确的交互提示。
3. 玩家按 E 打开底部对话面板，查看身份、关系和近期对话。
4. 玩家输入自然语言，NPC 根据人设、关系和记忆回复。
5. 界面用克制的方式显示关系变化；重要事实进入长期记忆。
6. 玩家关闭对话，NPC 恢复巡逻或工作状态，可继续探索其他角色。

## 5. 首发角色

| NPC | 默认定位 | 体验角色 |
| --- | --- | --- |
| 张旭 | Python / AI 工程师 | 提供严谨、直接、可验证的技术交流 |
| 樊玥燚 | 产品策划 | 追问目标、用户和取舍，推动玩家说清想法 |
| 胡佳烙 | 视觉与交互设计师 | 从视觉、交互和创意角度给出具体观察 |

三名角色的详细内容以 `Content/NPCProfiles.json` 为唯一可编辑来源。实际路径为 `../Content/NPCProfiles.json`，设计定义见 [NPCConfiguration.md](./Design/NPCConfiguration.md)。

三名角色均为原创虚构形象，不对应、不模仿任何真实人物外貌；姓名只作为游戏角色名称使用。

## 6. 视觉方向

首版采用原创的近未来创意工作室，而不是复刻原图中的日式房间：

- 俯视角像素场景，以 16 像素网格组织物体，以 2 倍或 4 倍整数缩放呈现。
- 主体使用雾白、石墨灰和低饱和青绿色；琥珀黄用于交互提示，珊瑚红用于错误和关系下降。
- 三个工作区分别用屏幕、便签墙和色板台表达工程、产品与设计身份。
- 家具、植物、灯光和屏幕形成有生活感的环境，但不遮挡行走路线和交互目标。
- 对话 UI 是贴底的工作台式面板，不使用全屏遮罩，不嵌套多层卡片。
- 中文正文保持清晰，像素图形不强迫中文字体也像素化。

## 7. 首版完成形态

发布目录包含一个玩家双击的 `Breakroom.exe`、后台服务、可编辑 NPC 配置和运行说明。游戏负责启动本地后端；后端以 mock 模式默认可用，在配置真实模型后切换为模型回复。

开发者仍可分别启动 Godot 项目和 FastAPI 后端进行调试。发布设计见 [ReleaseDesign.md](./Design/ReleaseDesign.md)。

## 8. 明确不做

- 不把产品做成聊天窗口套像素背景。
- 不让 LLM 直接移动角色、写数据库或决定关系分数。
- 不在首版加入任务、背包、多人、多场景或 NPC 管理后台。
- 不复制 Helix 源码，也不依赖 `Chapter11/Helix` 运行。
- 不用批量生成内容替代玩家的即时对话。
- 不追求大量角色；先让三名角色的完整体验成立。

## 9. 设计验收门

进入开发计划前，需要确认以下设计结论：

- 原创近未来创意工作室的视觉方向。
- 底部对话面板及关系等级可见的交互方案。
- NPC 配置文件是首版唯一编辑入口。
- Godot 进程作为一键入口并启动本地后端。
- 首版 SQLite 结构化记忆采用词项匹配，不承诺向量语义检索效果。
